# 设备验收清单

自动测试通过后，仍需在目标 Android 固件验收。以下项目没有勾选即不表示已完成设备验证。

- [ ] 旧插件看门狗/自启已关闭，旧进程停止。
- [ ] 新插件安装成功，重新打开网页不会产生第二个后台进程。
- [ ] 导入真实单文件配置；源域名、证书内容保留，账号文件权限 600。
- [ ] 无认证/证书错误，`ovpnc0` 获取地址，状态变为隧道已建立。
- [ ] 热点终端访问家庭 LAN 成功，公网出口与家庭实际出口一致。
- [ ] DNS 查询经过所填家庭 DNS，IPv6 外网不再绕行。
- [ ] WireGuard 开启情况下热点仍优先使用 OpenVPN。
- [ ] 拔断上级网络/停止服务端，热点不回落到蜂窝；恢复后可重连。
- [ ] 关闭网页后后台仍保持连接；设备重启后自启生效。
- [ ] 点击停止后，仅本插件规则被撤销，原有 WireGuard/蜂窝恢复。

首次切换请断开并重新连接热点终端，避免旧 conntrack 和 DNS 缓存干扰结果。
